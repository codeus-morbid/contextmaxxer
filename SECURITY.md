# Security policy

## Supported versions

Until the first stable release, security fixes target the latest published
beta only. Older binaries may not receive patches.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow from the repository's
**Security** tab. Include affected versions, impact, reproduction steps and any
suggested mitigation.

Do not disclose exploit details in a public issue. If private reporting is not
available yet, open a minimal issue asking the maintainer to enable a private
channel; omit the vulnerability details.

Please also report cases where Contextmaxxer unexpectedly sends source code or
credentials over the network. Normal indexing and querying are local; model and
runtime downloads are the expected network operations.
